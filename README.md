# Three China Terrain

固定中国及周边区域的 Three.js WebGPU 3D 地形底座。当前版本包含真实高程、TSL 程序化地表、基于小型程序化法线图的动态海洋、常驻省级信息、按站点省份加载的市级细节，以及基于 Three.js Inspector 的场景参数调试。运行时使用 WebGPU 后端，业务代码不包含旧 GLSL 材质兼容层。

原始地形和渲染网格均为 `512×384` Terrarium 高程，避免用无新增信息的顶点上采样增加启动开销。离线海陆分类是唯一判定基准：陆地高度不低于零，近岸平滑收敛到海平面，水域不生成真实海底。`1536×1152` 单通道有符号海岸距离场在 TSL 材质中负责高精度陆地/海水剔除和浅深海分色；海洋几何仅为两个三角形的承载平面。独立的中国焦点 Mask 会压低周边地形的视觉强度，为路线和站点保留层级。

行政区只保留省、市两级。省界和省名不参与 LOD，默认在全国视角常驻；市级数据只显示当前线路站点所在省份，并按相机距离阈值平滑淡入。市名以真实相机位置为基准做距离衰减、屏幕避让和密度限制。中国沿海范围优先采用 DataV 行政陆地，Natural Earth 仅提供周边陆地上下文，避免两套海岸简单并集造成中国省界与地形错位。边界文件只保存 UV 坐标，使用 WebGPU `Line2NodeMaterial`，按最终渲染网格自动细分，并和标签共同调用同一个最终三角网格高程采样函数；高度夸张后仍贴合地形。

通过 `renderer.setAnimationLoop()` 接入 Three.js 官方 Inspector，可检查 GPU/CPU 帧耗时、内存、时间线、TSL 节点，并在 Parameters 面板中实时调整地形、海洋、浅海范围、岸线泡沫、行政区和环境参数。海洋几何仍只有两个三角形，水面细节来自一次性生成的 256×256 程序噪声法线图和三组错向、多尺度滚动采样；采样会按视距抬高 mip LOD，并使用受控的细波高光代替场景方向光直接照射噪声法线，避免近景出现乳白色模糊光斑。

## 运行

```powershell
npm install
npm run data:all
npm run dev
```

生产构建：

```powershell
npm run build
npm run preview
```

## 数据

运行时只读取 `public/data` 中的轻量本地资产，不请求任何地图服务。当前地图资产总体积约 1.55 MiB；首屏只加载地形、压缩 Mask、省界和省名，市级边界与标签在首帧后异步加载。原始下载缓存位于 `data/cache`，不会进入生产构建。

数据来源与署名见 [ATTRIBUTION.md](./ATTRIBUTION.md)。中国地图公开发布前仍需由项目方完成边界、审图和商用授权确认。
