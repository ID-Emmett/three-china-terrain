# Three China Terrain

固定中国及周边区域的 Three.js WebGPU 3D 地形底座。当前版本包含真实高程、TSL 程序化地表、基于小型程序化法线图的动态海洋、常驻省级信息、按站点省份加载的市级细节，以及基于 Three.js Inspector 的场景参数调试。运行时使用 WebGPU 后端，业务代码不包含旧 GLSL 材质兼容层。

基础高程是 `512×384` Terrarium 数据。运行时由独立 Web Worker 生成 `768×576` 平滑渲染高度和四级地表 mip，再将归一化高程、局部明暗因子和细节法线打包到一张 RGBA 纹理。首屏不再下载重复的 surface 资产；派生结果写入 IndexedDB，后续访问直接复用。离线海陆分类仍是唯一判定基准：陆地高度不低于零，近岸平滑收敛到海平面，水域不生成真实海底。`1536×1152` 单通道有符号海岸距离场在 TSL 材质中负责高精度陆地/海水剔除和浅深海分色；海洋几何仅为两个三角形的承载平面。独立的中国焦点 Mask 会压低周边地形的视觉强度，为路线和站点保留层级。

地形几何由独立 Web Worker 生成，主线程只接收可转移的 typed array 并创建 `BufferGeometry`。全国、区域、细节三档 LOD 分别采用 4、2、1 的网格步长；所有 chunk 边界对齐到最粗网格并带向下 skirt。高一级网格同时保存父级表面位置，TSL 顶点阶段在切换时连续 geomorph，并使用带迟滞的距离阈值避免相机在临界位置反复切换。

行政区只保留省、市两级。省界和省名不参与 LOD，默认在全国视角常驻；市级数据只显示当前线路站点所在省份，并按相机距离阈值平滑淡入。市名以真实相机位置为基准做距离衰减、屏幕避让和密度限制。中国沿海范围优先采用 DataV 行政陆地，Natural Earth 仅提供周边陆地上下文，避免两套海岸简单并集造成中国省界与地形错位。边界文件只保存 UV 坐标，使用 WebGPU `Line2NodeMaterial`，按最终渲染网格自动细分，并和标签共同调用同一个最终三角网格高程采样函数；高度夸张后仍贴合地形。

通过 `renderer.setAnimationLoop()` 接入 Three.js 官方 Inspector，可检查 GPU/CPU 帧耗时、内存、时间线、TSL 节点，并在 Parameters 面板中实时调整地形、海洋、浅海范围、岸线泡沫、行政区和环境参数。海洋几何仍只有两个三角形，水面细节来自一次性生成的 128×128 程序噪声法线图和错向、多尺度滚动采样；采样会按视距抬高 mip LOD，并使用受控的细波高光代替场景方向光直接照射噪声法线，避免近景出现乳白色模糊光斑。

## 运行

```powershell
npm install
npm run data:all
npm run dev
```

生产构建：

```powershell
npm run build
npm run preview
```

## 数据

运行时只读取 `public/data` 中的本地资产，不请求任何地图服务。当前首屏资产约 1.55 MiB；省级视角按可见范围渐进加载 `8192x6144` 逻辑分辨率的 z8 relief 瓦片，完整瓦片集约 55 MiB，但桌面端最多驻留 36 张、约 38 MiB GPU 数据，窄屏或低内存设备降为 24 张、约 25 MiB。父级 relief 负责加载兜底并与高清页淡入融合，不需要等待整张高清图。派生地表不占网络体积，单张四级 RGBA mip 链约占 2.24 MiB GPU 数据。原始下载缓存位于 `data/cache`，不会进入生产构建。数据构建会先完整检查缓存输入，通过后才替换 `public/data`，避免缺少源文件时破坏已有发布产物。

数据来源与署名见 [ATTRIBUTION.md](./ATTRIBUTION.md)。中国地图公开发布前仍需由项目方完成边界、审图和商用授权确认。

## Progressive relief runtime

The relief tile pipeline now emits two geographic levels: `coarse` (4x3 pages)
for regional views and `fine` (16x12 pages) for close province views. Each level
has both lossless WebP and UASTC KTX2 assets. The renderer probes KTX2 support
once, uses GPU-compressed array textures when available, and falls back to the
existing Worker WebP decoder otherwise. Tile requests are cancellable when the
camera moves away, and stale pages are replaced with an LRU policy.

The generated KTX2 payload is about 26.55 MiB for fine tiles and 6.91 MiB for
coarse tiles. WebP files remain in the distribution as a compatibility fallback.

KTX2 assets are generated by the optional `basisu` dependency. Run
`npm install` before `npm run data:build`; if the optional encoder is unavailable,
the build stops before replacing the existing `public/data` directory.
